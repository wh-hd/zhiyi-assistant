## 📌 TL;DR（执行摘要）

- **核心目标**：打造微信生态内首个"AI 驱动的家庭健康管理助手"（非诊疗），以"AI 家庭健康自评"为差异化核心，以"家庭健康档案"为核心壁垒，服务 25-45 岁家庭健康决策者（女性为主）。

- **下一步**：冻结 PRD、启动 AI 大模型选型 POC、协调医学专家审核就医红线标准、10 周内交付 MVP 全量上线。

## 1. 产品目标（3 个清晰、正交的目标）

### 目标 1：成为微信生态内家庭健康管理的首选入口
- 以"AI 家庭健康自评"为首次留存钩子，建立"采集→分析→反馈→追踪"的需求闭环
- 3 个月内触达并服务 5,000-10,000 个活跃家庭（WAHF，北极星指标）
- D7 留存率≥12%，健康自评完成率≥50%

### 目标 2：以家庭健康档案为核心壁垒，构建高迁移成本的家庭健康运营体系
- 家庭档案建档率≥30%
- 档案维度覆盖：家庭成员、基础信息、慢病史、过敏史、用药记录、体检摘要、健康指标趋势
- 建档后用户迁移成本极高（参考蚂蚁 AQ 经验），形成自然护城河
- 从"工具"升级为"家庭健康陪伴"——家庭健康日历、状态互相感知、跨代协作

### 目标 3：坚守"非诊疗"定位，以信任锚点建立用户认可
- 每次AI咨询附非诊疗声明 + 就医红线机制
- 内容准确率抽检≥95%
- AI 健康咨询满意度≥75%
- 信任公式：**明确边界 + 边界内有干货 + 越界时清晰指引 = 用户认可**

## 2. 用户故事（5 个场景）

### US-1：深夜发烧的妈妈（画像D · 新手母婴健康关注者）
> 作为一名1岁宝宝的妈妈，凌晨2点孩子突然发烧38.5°C，我焦急又不敢立刻去医院。我希望打开智医助手，通过对话式AI描述孩子症状，立刻得到：①这个温度是否需要紧急就医的明确判断；②在家可以做的物理降温措施；③需要观察哪些恶化的信号。如果AI判断需要就医，直接告诉我应该去急诊。整个过程不超过3分钟，且明确告诉我"这是健康咨询不是医疗诊断"。

**验收标准：**
- Given 用户描述"1岁宝宝发烧38.5度"，When AI接收症状，Then 3秒内返回就医红线判断（建议就医但不紧急）+物理降温建议+观察信号清单+非诊疗声明
- Given 用户描述"3个月宝宝发烧39度持续不退"，When AI识别为就医红线，Then 首屏红色提示"建议立即就医"+儿科急诊引导

### US-2：异地子女整理父母用药（画像A · 三明治世代家庭健康守门人）
> 作为在上海工作、父母在老家的30+女儿，父亲有高血压和糖尿病，每天要吃5种药。我希望打开智医助手，拍一张父亲药盒的照片，系统自动识别药品名称和剂量，生成每日用药计划，到点通过微信订阅消息提醒父亲吃药。我还能在子女端看到父亲的"今日用药完成情况"，如果漏服了我会收到通知。父亲不会打字，可以用语音说"我今天血压145/90"，系统自动记录并生成趋势图。

**验收标准：**
- 拍照药盒→AI识别准确率≥85%→生成用药计划→用户确认生效
- 到点微信订阅消息推送用药人，确认后状态同步子女端，超30分钟未确认则子女端收漏服提醒
- 语音输入"今天血压145/90"→自动解析记录，语音识别准确率≥90%

### US-3：体检后焦虑的职场人（画像C · 健康焦虑青年）· P1
> 作为刚拿到体检报告的28岁白领，报告上5个指标标红但我看不懂。我希望打开智医助手，拍一下体检报告上传，AI逐项用大白话解释"这个指标偏高意味着什么、需不需要去医院、生活上怎么调整"，最后给我一个"未来3个月健康行动计划"。

**验收标准：**
- 拍照上传→AI识别准确率≥90%→逐项解读异常指标（通俗解释/可能原因/是否需就医/生活建议）→输出3个月健康行动计划

### US-4：慢病老人的日常健康记录（画像B · 银发慢病自我管理者）
> 作为65岁的高血压患者，我不太会用手机打字，但我会用微信语音。我希望打开智医助手，按住语音说"今天早上血压150/95，头有点晕"，系统自动识别并记录，还能看到这一个月的血压趋势图。如果连续3天血压偏高，系统提醒我"建议去医院复查"，同时自动把这条预警分享给我的女儿。整个操作不超过3步，字大、对比度高。

**验收标准：**
- 适老化模式开启→长按语音输入→自动解析数值+症状记录，操作步数≤3步
- 血压连续3次超140/90→触发预警通知用户"建议就医复查"+同步家庭管理员（子女）

### US-5：新用户"家庭健康摸底"（画像A · 首次使用场景）★核心差异化
> 作为第一次打开智医助手的用户，我不确定这个产品能帮我什么。我希望系统引导我用2-3分钟做一个"家庭健康自评"——通过对话式、选择题为主的方式，回答几个关于自己和家人健康状况的问题。做完后，系统给我一份"你的家庭健康关注清单"，明确告诉我"基于你的情况，建议重点关注这3件事"，并给出对应的行动建议。这样我能立刻感受到这个产品的价值，愿意继续使用。

**验收标准：**
- 新用户首次打开→引导进入自评→2-3分钟完成（选择题为主），完成率≥50%
- 自评完成→AI输出"家庭健康关注清单"含≥3条个性化建议，每条附行动指南+功能入口
- 自评结果→引导一键创建家庭档案+开启对应功能→30天后自动提醒复评

### 3.1 目标用户优先级

| 优先级 | 画像 | 年龄段 | 核心需求 | 付费意愿 | 设计重点 |
|:---:|------|:---:|----------|:---:|------|
| P0（核心驱动） | 三明治世代家庭健康守门人 | 30-45岁 | 家庭健康信息中枢、带动全家使用 | 中等偏高 | 家庭档案+跨代协作+自评引导 |
| P1（高价值） | 新手母婴健康关注者 | 25-35岁 | 儿童健康、疫苗提醒、育儿知识 | 最高 | 母婴健康场景+高敏感就医红线 |
| P1（高频） | 银发慢病自我管理者 | 55-75岁 | 用药提醒、指标记录、疾病科普 | 低（子女代付） | 适老化交互+语音输入+大字 |
| P2（流量） | 职场健康焦虑青年 | 25-35岁 | 体检解读、亚健康调理、心理疏导 | 中等 | 体检解读+AI咨询 |

### 3.2 核心痛点 → 需求映射

| 优先级 | 痛点 | 对应需求 |
|:---:|------|----------|
| P0 | 健康信息真假难辨 | 内容可信度标识体系 |
| P0 | 家庭健康信息分散割裂 | 家庭健康档案模块 |
| P0 | 小毛病"不敢去又怕拖" | AI健康咨询+就医红线 |
| P1 | 慢病用药管理靠记忆 | 用药提醒与管理 |
| P1 | 体检报告看不懂 | 体检报告解读 |
| P1 | 跨代健康沟通断档 | 家庭档案共享+预警通知 |
| P2 | 紧急情况判断无依据 | 就医红线+紧急指引 |
| P2 | 健康需求说不清（元痛点） | 家庭健康自评引导流 ★核心差异化 |
| P2 | 心理健康需求无处安放 | 心理健康疏导 |

### 3.3 "需求调研/健康自评"功能洞察（★核心差异化）
- 用户愿花2-3分钟做健康自评，**超5分钟流失极高**
- 期待**对话式/选择题为主**，非长表单
- 期待自评后有明确反馈（"你应该关注的3件事"），**不能填完没下文**
- 需形成 **"采集→分析→反馈→追踪"闭环**
- 持续性需求采集（融入日常交互）优于一次性长问卷
- 用户愿为"被倾听"提供反馈，但需**看到反馈被采纳**

### 3.4 非诊疗边界洞察
- 多数用户无法清晰区分"健康咨询"与"医疗诊断"，感性期待超出理性认知
- 用户期待AI做**分流判断**（"自己处理"vs"必须就医"），而非替代医生
- 关键公式：**明确边界 + 边界内有干货 + 越界时清晰指引 = 用户认可**

### 3.5 适老化洞察（置信度：高，已上调）
- 银发用户依赖语音输入和大字体，操作步数需≤3步
- 适老化不能是"附加功能"，必须是**核心路径设计**
- AI健康咨询接受度：25-34岁 64% vs 55岁以上 15%，差距超4倍
- 子女代管+老人自用的双端模式是关键交互模式

### 3.6 安全风险洞察（新增）
- **11%的用户表示AI聊天机器人会引发或加剧症状**（英国心理协会2025.11，高置信度）
- 就医红线机制不只是合规要求，更是**用户安全刚需**
- 需新增：情绪/焦虑安抚设计、心理安全网（自伤倾向转人工+危机热线）

### 7.2 AI健康咨询流程（含就医红线机制）

```
用户进入AI咨询
    │
    ├─ 展示非诊疗声明（"以下为健康咨询，不构成医疗诊断"）
    │
    ├─ 用户描述健康问题（文字/语音输入）
    │
    ├─ AI分析症状
    │
    ├─ 判断：是否命中就医红线？（12类危急症状）
    │   ├─ 是 ──→ 🔴 首屏红色提示："建议立即就医"
    │   │              ├─ 展示建议就诊科室
    │   │              ├─ 就医前的注意事项
    │   │              └─ 记录至家庭档案
    │   ├─ 涉及诊断/处方 ──→ 🟡 黄色提示："该问题建议咨询医生"
    │   │              ├─ 提供就医方向建议
    │   │              └─ 记录至家庭档案
    │   └─ 否 ──→ 🟢 提供健康咨询建议
    │                  ├─ 附非诊疗声明
    │                  ├─ 附内容来源标识
    │                  ├─ 生成健康行动建议
    │                  └─ 记录至家庭档案
    │
    ├─ 满意度评价弹窗（👍/👎 + 文字反馈）
    │
    └─ 结束
```

### 7.3 家庭健康自评流程（★核心差异化功能）

```
触发自评（首次使用 / 定期复评 / 用户主动）
    │
    ├─ 展示自评说明（"大约需要2-3分钟，帮您梳理家庭健康重点"）
    │
    ├─ Step1: 家庭基本信息 — 选择题：家庭人数 / 成员年龄段 / 你的家庭角色
    ├─ Step2: 成员健康状况 — 选择题+补充：是否有慢病 / 是否在用药 / 近期体检
    ├─ Step3: 健康关注点 — 多选：你最担心家人的哪些健康问题？
    ├─ Step4: 当前健康行为 — 选择题：家庭运动习惯 / 睡眠状况 / 饮食偏好
    │
    ├─ AI多维分析（综合家庭结构 + 健康状况 + 关注点 + 行为模式）
    │
    ├─ 输出：家庭健康关注清单
    │   ├─ Top 3 优先关注事项（每项含：为什么关注 / 建议行动 / 功能入口）
    │   └─ 整体家庭健康评分（可视化雷达图）
    │
    ├─ 引导行动（一键创建家庭档案 / 开启用药提醒 / 开启指标记录）
    │
    ├─ 自评结果存入家庭档案
    ├─ 设置30天后复评提醒
    └─ 需求采集：自评数据标记为用户需求信号→反馈至产品迭代
```

## 8. 安全设计要求（独立小节）

> 来源：瑞思与数析交叉印证——**11%的用户表示AI聊天机器人会引发或加剧症状**（英国心理协会2025.11，高置信度）。就医红线机制不只是合规要求，更是用户安全刚需。

| 安全设计 | 内容 | 优先级 |
|----------|------|:---:|
| **就医红线机制** | 识别12类危急症状（高热不退/胸痛/呼吸困难/意识模糊/剧烈腹痛/大量出血/严重过敏/中风征兆/抽搐/严重外伤/急性视力丧失/儿童高热惊厥）触发"建议立即就医"强提示+科室引导 | P0 |
| **情绪/焦虑安抚设计** | AI回答后避免"越问越慌"，对焦虑性咨询附加安抚性引导 | P0 |
| **心理安全网** | 检测到自伤/自杀倾向立即转人工+提供危机干预热线（全国心理援助热线400-161-9995） | P0 |
| **非诊疗声明** | 每次AI咨询末尾附"本建议仅供参考，不构成医疗诊断，请及时就医"轻量提示 | P0 |

## 9. Non-goals（明确不做什么）

| 类别 | 不做的事 | 原因 |
|------|----------|------|
| 在线问诊 | 不做实时/异步在线问诊、不连接医生 | 坚守非诊疗定位，避免持牌合规风险 |
| AI诊断 | 不做疾病诊断、不输出确诊结论 | AI诊断存在幻觉风险，且无诊疗资质 |
| 处方开具 | 不开处方、不推荐具体药物 | 无互联网诊疗资质，合规红线 |
| 电商购药 | 不做药品/保健品电商、不卖货 | 避免利益冲突影响咨询客观性 |
| 运动健身 | 不做运动记录/健身课程/卡路里计算 | 与Keep/薄荷正面竞争，非核心场景 |
| 体重/饮食管理 | 不做体重管理/饮食记录/卡路里摄入 | 非核心场景，避免功能膨胀 |
| 智能硬件自研 | 不自研健康硬件设备 | MVP聚焦软件体验，P2仅做第三方设备接入 |
| 心理治疗 | 不做心理疾病治疗/不开药 | V2仅做轻量心理疏导+量表自评+引导专业咨询 |
