## 📌 TL;DR（执行摘要）

- **市场窗口**：互联网医疗进入存量成熟期（2025 年约 4769 亿、4.11 亿用户首次微降），但大模型降幻觉 + 国家"居民健康助手"政策红利，正打开 C 端 AI 健康对话的新窗口；小程序是轻量高触达的首选载体。
- **产品定位**：微信小程序形态的 **AI 家庭健康助手**（非诊疗定位），以 AI 对话为入口、**家庭健康管理**为差异化主线，做"最懂你和家人健康的 AI 分诊哨兵"，而非又一个互联网医院。
- **差异化切入**：以 ① AI 症状自查深度分诊 ② 家庭健康档案枢纽 ③ 报告智能解读 + 纵向趋势追踪 三个能力切入，避开与微医/京东健康的全流程医疗服务正面竞争。
- **底线原则**：数据合规为不可逾越红线，AI 定位"赋能不替代"，关键决策（开方/急症预警）需执业医生兜底。
- **下一步**：确认定位与首批 MVP 范围后，由析客撰写完整 PRD，由路径规划迭代路线图。

## 1. 市场与趋势判断（来自数析）

| 指标 | 数值（估算） | 趋势 |
|------|------|------|
| 互联网医疗市场规模（2025） | 约 4769 亿元 | +13%，增速回落，进入存量成熟期 |
| 用户规模（2025） | 约 4.11 亿人 | 首次微降（-1.68%），增长触顶 |
| 在线问诊渗透率 | 15%（2020）→ ~45%（2025） | 线上就医习惯已养成 |
| 互联网医院数量 | 3756 所（2025.9） | 持续扩张，但资质门槛高 |
| 微信小程序用户 | 约 9.49 亿，月活破 10 亿 | 医疗健康轻量入口首选 |

**五条关键趋势**：
1. 在线问诊常态化，平台转入存量争夺
2. 银发族数字化健康需求爆发（慢病管理、用药提醒、家庭代管）
3. 慢病管理数字化加速（多省试点"数字慢病管理示范省"）
4. AI 健康应用认知度快速提升（蚂蚁"阿福"月活超 1500 万，101 个医疗 AI 模型已备案）
5. 家庭健康管理兴起（"一人管理全家健康"成增量需求）

**政策导向**：
- ✅ 利好：国家五部门"人工智能+医疗卫生"政策明确探索"人人可享的居民健康助手"
- ⚠️ 红线：AI"赋能不替代"，不得替代医师诊疗；涉诊疗须依托实体医疗机构 + 互联网医院资质
- ⚠️ 数据：健康数据属敏感个人信息，"最小必要"采集、加密存储、明确授权是硬门槛

> **一句话判断**：存量成熟市场里，大模型 + 政策红利打开了 C 端 AI 健康对话新窗口；建议定位"非诊疗"AI 家庭健康助手，以小程序为载体、AI 对话为入口、家庭健康管理为差异化、数据合规为底线。

## 2. 目标用户与核心痛点（来自瑞思）

### 2.1 五类目标用户分层

| # | 用户群体 | 占比 | 核心特征 |
|---|---------|------|---------|
| 1 | 轻症/急性不适人群 | ~35% | 18-40 岁，"先上网查"，回避跑医院，对信息可靠性敏感 |
| 2 | 慢性病患者 | ~25% | 高血压/糖尿病等，需长期管理，依从性差，黏性最强 |
| 3 | 中老年及子女/家属 | ~20% | 老人数字能力弱、子女异地焦虑、子女是决策与付费方 |
| 4 | 孕产妇及育儿家庭 | ~10% | 健康焦虑高、信息需求密集、对权威信息极度渴求 |
| 5 | 健康关注/体检人群 | ~10% | 城市白领，定期体检，需求集中在报告解读与风险预警 |

### 2.2 痛点矩阵（精选）

| 群体 | 核心痛点 |
|------|---------|
| 轻症人群 | 自查信息鱼龙混杂（"百度看病癌症起步"）；小毛病跑医院成本高；无法判断"该不该去、挂什么科" |
| 慢病患者 | 用药依从性差缺乏提醒；指标数据碎片化；复诊开药繁琐；缺乏专业随访 |
| 中老年及家属 | 数字操作门槛高需代办；异地子女无法实时了解父母健康；病史分散、换院重讲 |
| 孕产妇 | 不适"正不正常"缺即时判断；产检报告看不懂；育儿信息过载难辨权威 |
| 健康关注人群 | 体检报告看不懂不知严重程度；科普碎片化营销混杂；缺个性化指导 |

### 2.3 高频场景 Top5

1. **深夜突发不适自查** → AI 引导式问诊给出"居家观察 / 立即就医"判断
2. **体检报告解读** → 拍照上传，逐项通俗翻译 + 行动建议
3. **异地子女远程管理父母慢病** → 绑定档案、远程查看趋势、异常同步预警
4. **复诊开药/慢病续方** → 在线复诊开方 + 药品配送 + 自动用药提醒
5. **孩子发烧慌乱求助** → 按月龄/体温/症状给出护理建议 + 就医预警信号

### 2.4 用户期望与顾虑

- **期望**：快速准确判断严重程度、把医学术语翻译成人话、7×24 即时响应、一站式打通全流程、持续记录形成健康档案
- **顾虑**：误诊风险（最高）、隐私泄露、信任度不足、责任归属模糊、适老性担忧

> **方向启示**：以"信任"为核心壁垒（AI 初筛 + 医生审核双轨）；以家庭健康档案为枢纽构建网络效应（一人使用→全家受益）；切入"报告解读 + 症状自查"两个高频低门槛入口，再向问诊/续方延伸；慢病管理做深做透是留存与商业化主战场；适老化是关键增长杠杆而非附属功能。

## 3. 竞品格局与差异化机会（来自竞析）

### 3.1 竞品四大阵营

| 阵营 | 代表 | 核心优势 |
|------|------|---------|
| 互联网医疗平台（综合） | 微医、平安健康、京东健康、好大夫、丁香医生 | 全流程医疗服务闭环 / 医生资源 / 自营药房 |
| 科技巨头 AI 入口 | 腾讯健康、百度灵医 | 微信原生入口 + 家庭场景 / B 端 AI 能力 |
| 健康管理类 | 薄荷健康 | 垂直体重/营养管理 |
| 医院自有小程序 | 各三甲院挂号小程序 | 信任度高但体验参差 |

**格局判断**：微医与腾讯健康功能覆盖最全；腾讯健康在"家庭场景 + 微信原生"独占优势；丁香医生占科普认知、好大夫偏严肃问诊；百度灵医是 B 端能力供应商不直接 C 端。

### 3.2 主流 9 大功能模块

智能导诊/AI 问诊、在线问诊、预约挂号、报告查询与解读、电子处方与购药、慢病管理、健康档案、健康科普、家庭健康管理。

### 3.3 三个差异化切入机会

| 机会 | 现状空白 | 智医助手怎么做 |
|------|---------|---------------|
| **AI 症状自查做深** | 现有产品多停在"导诊推荐科室"，未真正判断"要不要紧、要不要去、去什么级别" | 结合档案 + 多轮对话 + 知识图谱，输出分级建议（居家/社区/急诊），填补"去医院前"决策空白 |
| **家庭健康档案为主线** | 腾讯健康首创但仍偏工具属性 | 全家档案管理 + 家庭级异常预警 + 家庭用药协同 + 亲子追踪，依托微信家庭群裂变 |
| **报告解读 + 纵向趋势** | 多数平台仅单次查询，缺跨年趋势 | 做"个人健康时间轴"，历次数据纵向对比，AI 识别趋势变化主动预警 |

## 4. 产品定位与差异化主线（主理人综合）

```
┌─────────────────────────────────────────────────────┐
│  智医助手 = AI 家庭健康助手（微信小程序）            │
│                                                     │
│  入口角色：AI 分诊哨兵（去医院前的决策助手）         │
│  留存角色：家庭健康管家（全家健康的长期陪伴者）       │
│                                                     │
│  不做：互联网医院、首诊诊断、处方出具（合规边界）     │
│  依托：合作互联网医院资质做复诊续方（延伸阶段）       │
└─────────────────────────────────────────────────────┘
```

**定位三角**：
1. **AI 对话为入口** — 大模型让自然语言健康对话体验质变，政策支持"居民健康助手"
2. **家庭健康管理为差异化主线** — 子女为父母建档、妈妈为孩子建档是天然裂变路径
3. **信任渐进式升级** — 先在低风险场景（看懂报告、判断要不要去医院）证明价值，再引导至高价值交易（问诊、续方）

## 5. 功能方向大纲（按优先级分层）

> 这是方向大纲，非最终需求池；具体验收标准与工作量留待析客撰写 PRD 时细化。

### P0 · MVP 核心入口（验证价值与信任）

| # | 功能方向 | 解决的痛点 | 关键实现要点 |
|---|---------|-----------|-------------|
| P0-1 | **AI 智能症状自查** | "该不该去医院、挂什么科" | 引导式多轮问诊（文字+语音）；结合档案+知识图谱；输出分级建议（居家观察/社区就诊/急诊）+ 推荐科室；嵌入医学规则库防幻觉；明确"非诊断、仅供参考"免责声明 |
| P0-2 | **体检/检查报告智能解读** | 报告看不懂、不知严重程度 | 拍照 OCR 识别（微信原生能力）；逐项通俗翻译；标注需关注项 + 就医建议 + 生活方式调整；支持一键导入微信文件 |
| P0-3 | **家庭健康档案** | 健康信息分散、异地代管难 | 一人建档、全家共享；子女远程查看父母数据；成员切换；基础信息/病史/过敏史/用药记录；数据加密 + 授权管理 |
| P0-4 | **隐私授权与数据合规底座** | 健康数据敏感、用户顾虑 | 最小必要采集告知；明文授权同意；数据加密存储/传输；用户可控授权与删除；不存储完整病历 |

### P1 · 留存与价值延伸（建立长期关系）

| # | 功能方向 | 解决的痛点 | 关键实现要点 |
|---|---------|-----------|-------------|
| P1-1 | **用药提醒与慢病指标追踪** | 依从性差、数据碎片化 | 服药打卡 + 微信订阅消息提醒；血压/血糖记录 + 趋势可视化；异常指标主动预警并通知家庭成员 |
| P1-2 | **在线图文问诊 + 复诊续方 + 药品配送** | 复诊取药繁琐 | 依托合作互联网医院资质；区分首诊（禁止线上）/复诊/慢病随访；药师审核 + 处方流转 + 配送 |
| P1-3 | **异常指标主动预警** | 病情变化无人提醒 | 趋势异常自动推送；分级预警（关注/就医/急诊）；家庭级联动通知 |
| P1-4 | **个性化健康科普推送** | 科普碎片化、营销混杂 | 基于档案/近期自查"内容找人"；AI 生成 + 权威审核；信源可溯源；拒绝软文 |
| P1-5 | **适老化设计** | 老人数字门槛高 | 原生大字版；语音交互；子女代办模式；简化操作路径 |

## 6. 关键实现细节考量

### 6.1 合规红线（不可逾越）

- **非诊疗定位**：产品明确"健康咨询与管理"，AI 输出标注"仅供参考、非诊断"
- **首诊禁止线上**：在线问诊仅限复诊/慢病随访
- **处方资质**：涉处方药须依托合作互联网医院，经执业医师开具 + 药师审核
- **AI 赋能不替代**：关键决策（开方/急症预警）须人工医生介入或复核
- **数据合规**：遵循《个人信息保护法》《医疗卫生机构数据安全管理办法》，最小必要、加密、授权、可删除

### 6.2 信任建设机制

- **双轨兜底**：AI 初筛 + 医生审核，关键建议标注"已由执业医师审核"
- **权威背书**：合作医院/医生 IP、内容专业度、服务保障（如问诊不满意退款）
- **透明可溯源**：科普内容标注信源与审核医生，AI 建议可解释

### 6.3 技术要点

- **防幻觉**：医学知识图谱 + 规则库约束（参考微医 1.3 万专病规则 + 47 万合理用药规则）
- **多模态**：OCR 报告识别、语音输入、皮肤拍照初筛
- **触达**：微信订阅消息替代 APP 推送（用药/报告/随访提醒）
- **性能**：主包 ≤2MB，核心问诊/自查放主包，挂号/购药分包按需加载

## 7. 微信小程序形态特殊考量

**优势利用**：
- 即用即走、零安装 → 适合低频医疗场景，降低决策成本
- 微信社交关系链 → 家庭群分享、AI 解读一键发送，家庭健康管理天然土壤
- 订阅消息 → 用药/报告/随访精准触达，不被系统拦截
- 微信支付 → 挂号/问诊/购药支付无缝衔接
- 原生能力 → OCR、语音输入、摄像头可直接调用

**限制与应对**：
- 包体积限制 → 合理分包，核心功能放主包
- 无法后台常驻 → 配合可穿戴/微信运动数据或用户主动录入，不做实时监测
- 医疗合规 → 全程免责声明与边界提示
- 信任建立难 → 通过权威背书 + 内容专业度 + 服务保障沉淀品牌
